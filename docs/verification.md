检查点：

1. 布局：顶部项目栏、左侧步骤及设置、右侧画布、底部键盘提示一致。

## 更新：画布内快速动画

按用户反馈，原概念中的常驻侧栏、步骤命名、对象计数及效果/时长设置已移除。当前视觉依据为用户明确要求的 PowerPoint 式画布操作。

- 出现、消失、动画列表已加入原生顶部绘图工具栏，未选中对象时禁用动画按钮。
- 每次默认新增一步；可用下拉菜单或列表的步骤行选择已有步骤。同批选中的多个对象同时加入。
- 对象旁编号对应步骤，绑定文本不重复显示编号；出现为紫色，消失为浅红色。
- 点击编号定位对象和步骤。列表默认收起，支持按对象调整步骤、排序、移除动画和空步骤清理。
- 演示模式隐藏编号和编辑列表，统一 450ms 淡入淡出，保留减少动态效果偏好。
- 兼容此前导出的文件，内部旧名称仅用于格式兼容，不显示在界面。

内置浏览器实测：选中用户对象后新增第5步消失，编号立即显示；播放到第五步用户消失；Esc恢复完整画布；将动画移到第4步后空的第5步移除；上下排序后编号更新；移除测试动画后恢复原四步。拖动服务对象50px/50px后编号同步移动，随后撤销测试拖动。缩放时编号坐标同步更新。刷新后项目仍正确恢复。测试动画已清理。

检查了默认桌面和390×844窄屏。修复窄屏按钮裁切：原生绘图工具可横向滚动，动画按钮在下一行完整可见，无页面横向溢出。复核顶部控件、默认收起列表、编号对齐、出现/消失配色、列表文字与排序、演示时隐藏标记。截图通过内置浏览器保存，并以view_image查看：animation-toolbar-preview.png、animation-list-preview.png。没有沿用已被用户否定的侧栏设计。

## 修复：重置后动画编号从 1 开始

原生重置会把旧元素标记为 isDeleted，但外层 steps 原先仍保留其对象引用，导致新动作接着排到第5步。现在画布变更、初始恢复和导入时同步清理失效动画引用及空步骤；全部清空时也移除旧镜头步骤，并恢复「新步骤」作为添加目标。已有错误保存记录也会自动修正。

新增3项回归测试覆盖清空全部对象后重新添加、旧保存文件中的失效引用、部分删除后的有效动画保留。共5项测试与生产构建通过。在独立测试端口5187执行原生「重置画布」并确认，动画列表为空；绘制新矩形后点出现，画布标记及列表均为第1步。测试截图：reset-numbering-preview.png。测试页面已关闭，不修改用户当前画布。

## Unfold 与动画开始方式

- 每一步提供单击时、与上一动画同时、上一动画之后；老项目缺省按单击处理，存储格式及 IndexedDB 键保持兼容。
- 自动播放调度以单击组为单位；同时动画共享时间起点，之后动画等待上一动画 450ms 完成。动画期间返回、跳至下一组或退出均取消旧播放帧。进入演示先显示 0/N 等待首次点击。
- 独立示例页 127.0.0.1:5188 验证：第 2 步同时、第 3 步之后、第 4 步单击；首次单击同时展示用户、箭头和 API，之后无需点击自动展示数据库，停在 3/4；下一次单击到 4/4；返回依次恢复 3/4 与 0/4。中途退出后完整场景与编号恢复。
- 标题栏、网页标题、favicon 使用 Unfold，Logo 为可编辑 SVG 的三折展开页。截图：unfold-animation-starts.png。
- npm test 8 项通过，涵盖混合调度、同时淡入、后续淡出、镜头同步、减少动态效果和旧项目缺省方式；npm run build 通过。
